ZMP - online co-op for The Legend of Zelda: Ocarina of Time
===========================================================

Up to 6 players, each with their own real Link, all seeing exactly the same world. Built on Ship of Harkinian.
This package contains NO part of the original game: you need your own ROM.

FIRST TIME
1. Unzip this folder somewhere normal (for example C:\Games\ZMP), not inside Program Files.
2. Open soh.exe. If Windows says "Windows protected your PC": More info > Run anyway.
3. "No O2R files found. Generate one now?" > Yes > choose your ROM (.z64/.n64/.v64).
   Wait one or two minutes. "Extract another?" > No.
   EVERYONE IN A ROOM MUST USE THE SAME ROM VERSION and this same zip.
4. The "Sala ZMP" window opens (if hidden: Esc > Network > ZMP > "Mostrar u ocultar ventana de sala").
   Tabs: Join / Host / Profile / Advanced. Profile tab: type your name > Change name.

HOST (one of you)
1. Host tab > Who can join: "My local network and whoever has the code" > Host and play.
   (Room and password empty = made up for you. If Windows Firewall asks about zmp-server: Allow access.)
2. Press "Copy code" and send the code (ZMP-....) to your friends. Whoever has it can join: send it privately.
3. Load your save (or start a new one). That becomes the group's game.
4. The "From the internet" line says whether friends on the internet can reach you. If it says CGNAT,
   "Router without UPnP" or that the router did not open the port, see "plan B" in the guides (link below).
   Stop hosting (or closing the game) stops the server and removes the router rule.

FRIENDS
1. Stay on the file select screen (do not load a save).
2. Join tab > paste the code > "Join with this code". In a few seconds you appear next to the group.
   Same house? The game also appears under "On your local network": type the room password in the
   Password field, then press Join on that row.

PLAYING: to revive a downed friend, stand next to them and hold A for 3 seconds.

PRIVACY: nothing is uploaded. The game only connects to the server you type or the code carries, and to open
the port it talks only to your own router. The "logs" folder (and zmp-host\zmp-server.log when you host)
stays on your PC.

Guides (plan B hosting, browser mode, troubleshooting):
  https://github.com/S-BlackDragon/zmp-oot64/tree/zmp/docs-zmp/en

Problems: send the "logs" folder of this folder with a description and the time it happened.
